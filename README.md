# Todoboy Desktop releases

Signed and notarized builds of **Todoboy Desktop** for Apple Silicon Macs.

**Download the newest build:** https://todo.boy.dev/download/mac

Each release here is published automatically when a new build ships, and the
`latest` release is always the newest one. `SHA256SUMS` sits next to every DMG.
This repository holds binaries only; the application source is private.

Todoboy Desktop is a fork of [T3 Code](https://github.com/pingdotgg/t3code) (MIT).
Its licence and third-party notices are bundled inside the app
(Settings → Open-source licenses).
